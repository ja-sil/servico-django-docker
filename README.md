# Serviço Django Docker

Projeto desenvolvido como atividade prática utilizando o framework Django e Docker. O objetivo é executar uma aplicação web Django dentro de um container Docker utilizando Docker Compose.

## Tecnologias utilizadas

- Python 3.14
- Django 6.0.7
- Docker
- Docker Compose
- Git e GitHub

## Pré-requisitos

Antes de executar o projeto, é necessário ter instalado:

- Python 3.14
- Docker Desktop
- Git
- Git Bash (Windows)

## Como executar o projeto

### 1. Clonar o repositório

```bash
git clone https://github.com/SEU-USUARIO/servico-django-docker.git
```

### 2. Entrar na pasta do projeto

```bash
cd servico-django-docker
```

### 3. Construir a imagem Docker

```bash
docker-compose build
```

### 4. Executar o container

```bash
docker-compose up
```

### 5. Acessar a aplicação

Abra o navegador e acesse:

```
http://localhost:8000
```
